# MVP Requirements — Дневник снов

## Продукт
Telegram-бот для психологической интерпретации сновидений.

## Позиционирование
«Сны — это язык вашего бессознательного. Мы не гадаем, мы анализируем.»

## Команды MVP
- `/start` — приветствие
- `/help` — справка
- `/interpret` — интерпретация сна
- `/history` — последние 10 снов
- `/stats` — эмоциональная динамика
- `/insights` — паттерны
- `/settings` — настройки
- `/clear` — удалить историю
- `/delete_my_data` — GDPR удаление

## Критерии приемки
- [x] Бот отвечает на /start с описанием подхода
- [x] Принимает текст сна (до 4000 символов)
- [x] Валидация на эзотерику (стоп-слова)
- [x] JSON-ответ со всеми полями
- [x] Сохранение в PostgreSQL с шифрованием
- [x] /history — последние 10 снов
- [x] /stats — эмоциональная динамика
- [x] Голосовой ввод через Whisper
- [x] Оценка точности 1–5
- [x] /delete_my_data — полное удаление
- [x] docker-compose up
- [x] Логирование INFO
